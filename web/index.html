계산 방식과 해석 범위

실제 검증 사례
학습에서 해당 참가자를 제외한 RF와 저장된 Python SHAP 0.48.0, LIME 0.2.0.1, Alibi 0.9.6 결과입니다.
값을 직접 바꾼 경우
동일 RF의 실제 추론 + 정확한 path-dependent Tree SHAP. 16개 원본 사례의 각 SHAP 값과 Python 결과 일치를 검증했습니다. LIME과 anchor-style 규칙은 별도의 브라우저 근사이며 Python 패키지 결과가 아닙니다.
HCI 사용자 실험
16명·4조건 비교의 배정표와 질문지는 저장소에 있습니다. 실제 참여자 실험과 생산성 개선 검증은 아직 수행하지 않았습니다.
이 앱은 수업용 연구 데모입니다. 모델은 WESAD의 실험 조건을 구분합니다. 개인의 스트레스 진단, 원인, 휴식의 효과를 확정하지 않습니다. 임의값 조합은 실제 신체 상태로 가능한 조합이 아닐 수 있습니다.
