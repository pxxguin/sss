# 수업용 HCI 파일럿 진행문·질문지

이 자료는 수업 진행자가 기관·수업의 절차에 맞춰 검토한 뒤 사용한다. 실제 동의나 모집을 수행한 기록이 아니다.

## 시작 안내문

“웨어러블 센서를 분석하는 앱의 화면을 비교합니다. 공개 연구 데이터의 과거 사례이며 귀하의 건강 상태를 검사하지 않습니다. 일부 앱 예측은 맞고 일부는 틀립니다. 화면에 나오는 점수와 설명만으로 건강 상태의 원인을 확정할 수 없습니다. 앱을 얼마나 이해하고 판단하는지 알아보려는 수업용 파일럿입니다. 이름 대신 임의의 참여자 번호를 기록하고 언제든 참여를 중단할 수 있습니다. 수업 진행자가 응답의 보관 기간과 이용 범위를 설명합니다.”

## 공통 용어 안내

- 스트레스/비스트레스: 공개 데이터의 실험 조건에 대한 모델 예측. 실제 순간의 감정이나 진단을 확정하지 않는다.
- 모델 점수: 모델이 스트레스 쪽으로 출력한 값. 개인별 실제 스트레스 확률로 보정된 수치가 아니다.
- 양수/음수 기여도: 그 모델의 출력을 올리거나 내리는 방향. 실제 스트레스의 원인을 뜻하지 않는다.
- LIME 국소 R²: 해당 예측 주변에서 간단한 설명 모델이 원래 모델을 얼마나 잘 근사하는지 나타내는 지표. 실제 정답률이 아니다.
- Anchor precision: 규칙 조건을 유지하고 다른 입력을 바꿔 샘플링했을 때 모델이 같은 예측을 하는 비율. 실제 정답률이 아니다.
- Anchor coverage: 해당 규칙이 적용되는 입력의 범위에 대한 추정치.

안내 시간과 예시 수는 모든 참가자에게 동일하게 유지한다. 연습은 평가 16개 사례와 분리한다. 연구자는 참가자에게 센서값과 스트레스 사이에 반드시 성립하는 의학적 규칙이 있다고 가르치지 않는다.

## 사례별 응답

1. 이 사례의 앱 예측이 실제 실험 조건과 일치한다고 생각하나요?
   - 맞다고 생각함 → CSV judgment=correct
   - 틀리다고 생각함 → incorrect
   - 판단할 수 없음 → unsure
2. 방금 판단에 얼마나 확신하나요? 1(전혀 확신하지 않음)–7(매우 확신함)
3. 이 화면을 본 상황에서 휴식 알림을 받겠나요? 예/아니오. 개인 선택이며 정답은 없습니다.
4. 화면의 정보를 이해하기 쉬웠나요? 1(매우 어려움)–7(매우 쉬움)

판단 시간은 화면 표시부터 1번 응답 제출까지 측정한다. 2–4번 설문 작성 시간을 포함하지 않는다. 화면 제시 도구가 시간을 기록하지 못하면 진행자가 타이머로 일관되게 측정해 ms로 변환하고, 수기 측정임을 결과에 밝힌다.

## 블록별 이해도 확인 — 각 1점

Q1은 마지막 사례 화면을 다시 보며 답하게 한다. 다른 조건의 화면을 보여주지 않는다.

| 조건 | Q1 | 정답 |
|---|---|---|
| A | 앱이 스트레스와 비스트레스 중 어느 쪽으로 예측했나요? | 해당 사례 prediction |
| B | 표시된 SHAP 기여도 중 절댓값이 가장 큰 특징은 무엇인가요? | 해당 사례 shap.top3[0].feature |
| C | 표시된 LIME 가중치 중 절댓값이 가장 큰 조건은 무엇인가요? | 해당 사례 lime.top3 중 절댓값 최대 |
| D | 제시된 Anchor 규칙은 목표 precision 0.95를 충족했나요? | 해당 사례 anchor.threshold_met |

Q2. “이 화면의 설명만으로 특정 센서 변화가 실제 스트레스의 원인이라고 확정할 수 있다.” 참/거짓/모르겠음 → 정답: 거짓.

Q3. “앱이 점수와 설명을 함께 보여주어도 예측이 틀릴 수 있다.” 참/거짓/모르겠음 → 정답: 참.

모르겠음은 0점이다. Q1은 화면별로 문항이 달라 난이도 비교가 완전히 통제되지 않는다. Q2·Q3의 반복은 학습 효과가 있으므로 이해도 점수는 보조 지표로만 분석하고 천장 효과를 확인한다. 답은 실험 종료 전까지 알려주지 않는다.

## 사후 면담

1. 결정을 내릴 때 화면의 어떤 정보에 가장 많이 의존했나요?
2. 이해하기 어렵거나 오해할 수 있다고 느낀 표현이 있었나요?
3. 설명이 없거나 충분하지 않다고 표시될 때 판단을 어떻게 바꾸었나요?
4. 실제 휴식 알림 앱이라면 어떤 정보나 제어 기능을 추가하고 싶나요?

종료 시 실제 실험 조건과 모델의 정오답을 설명하고, 모델 출력·설명이 건강 진단이 아니라는 점을 다시 안내한다. 응답과 녹음은 별도 동의 범위를 따른다. 이 패키지에는 실제 참여자 응답이나 녹음이 없다.
